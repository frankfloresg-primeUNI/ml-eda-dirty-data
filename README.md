# Machine Learning - EDA

Proyecto de Machine Learning desarrollado para el curso de IEEE CIS UNI.

## Objetivo

Realizar un análisis exploratorio de datos (EDA), identificar problemas de calidad en los datos y plantear una hipótesis sobre las variables relacionadas con el objetivo.

## Estructura

- `data/`: datos del proyecto
- `notebooks/`: análisis exploratorio
- `src/`: código fuente
- `models/`: modelos entrenados
- `requirements.txt`: dependencias
